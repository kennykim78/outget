## 0. 진화 경로 (왜 여기에 도달했나)

교육정보 포털(LECV) → 학원데이터랩 → 아울렛 가격 애그리게이터 → **아울렛 구매대행 마켓플레이스**.
공통 교훈: *데이터 합법성*이 사업 생존을 가른다. 포털/커뮤니티 원문을 서버에 모으는 모든 안은 데이터베이스권(저작권법 §93) + **부정경쟁방지법 (카)목**(야놀자 v 여기어때) 리스크에 막힌다. 그래서 **"거래가 데이터를 만드는"** 구조로 전환 — 데이터를 긁지 않고, 구매대행 거래의 부산물로 *내 소유* 데이터를 축적한다.

## 1. 한 줄 정의 · 핵심 가치

오프라인 아울렛의 파편화된 할인 정보를 **지도 위**에서 보여주고, 방문이 어려운 소비자와 **현장 구매대행자**를 연결하는 마켓플레이스.

- 가치 제안: "여주/김포 아울렛 특가를, 안 가도 대행으로." + "흩어진 정보를 지도 한 장으로."
- 코어 동력(데이터·기술이 아니라): ① **신뢰 가능한 대행자 공급** ② **분쟁 해결**.

## 2. 핵심 원칙

| # | 원칙 | 내용 |
|---|------|------|
| 1 | Legal-Safe Data | 지속 크롤링 금지. 데이터는 *공식 공개 사실* + *자체 거래/UGC*로만 축적 |
| 2 | 2층 가격 | **추정·참고가**(공식 홍보 기반) ↔ **현장 확인가**(대행자 갱신)를 명확히 분리 |
| 3 | 순수 중개 | 플랫폼은 통신판매**중개자**. 거래 당사자(대행자·소비자) 아님을 고지. 자금 미보유 |
| 4 | 무수수료 MVP | 초기 중개수수료 0 (검증 단계 전술). 매출 경로는 §7 |
| 5 | 책임의 구조화 | "약관으로 면책"이 아니라 "구조적으로 당사자가 책임지는 거래"로 설계 |

## 3. 데이터 전략 (2층 + 시드)

### 3-1. 가격 2층 구조

**A. 추정·참고가 (플랫폼 생성, 참고용으로 격하)**
- 출처: 아울렛/브랜드가 **공식 공개한 홍보**("최대 30% 할인" 등) + 정가(MSRP).
- 입력값(정가·품번)도 **깨끗한 소스만**: 브랜드 공식 / 네이버쇼핑 API(약관 내). 여기서 커뮤니티·쇼핑몰을 긁으면 (카)목이 뒷문으로 들어옴 — 금지.
- **표기 규칙 (표시광고법 방어 — 확정 표기 절대 금지):**
  - "최대 30%" = 할인율 ≤ 30% → 30%로 단정하면 *최저값 편향* → **보수적/범위 표기**.
  - 권장 카피:
    ```
    [추정·참고용]  실제 매장가 아님
    정가 55,000원 · 공식 "최대 30%" 기준
    예상 39,000 ~ 55,000원
    ※ 현장 확인 필요 · 구매대행 확인 시 갱신
    ```
  - 점(단일가) 아닌 **범위** + "추정/참고/실제가 아님/현장확인" 라벨 + 출처 명기.

**B. 현장 확인가 (대행자 생성, 신뢰 앵커)**
- 대행자가 현장에서 실측·갱신한 단일가. 책임은 갱신한 대행자에 귀속.
- 표기: 추정가와 **시각·문구로 확실히 구분**.
    ```
    [현장 확인가 ✅]  39,000원
    OO 대행자 · 2026-06-07 확인
    ```

### 3-2. 초기 데이터 시드 전략

1. **창업자 직접 입력 (1차·주력)**: 앵커 아울렛 현장 검증 데이터를 직접 입력(컨시어지). 100% 합법·내 소유.
2. **1~2회 부트스트랩 크롤링 (한정·예외)**: 콜드스타트 해소용 *일회성* 시드. **지속 크롤링 아님.**
   - 🔴 **리스크 잔존**: 일회성이라도 커뮤니티 누적 게시판은 (카)목 "성과", 단일 복제도 저작권/DB권 성립 가능. *위험이 0이 아님* — 변호사 자문 권장.
   - 가드레일(채택 시 최소 안전장치):
     - **팩트만 추출**(지점·품번·가격·좌표). 본문·사진·댓글 **1:1 미러링 절대 금지**.
     - robots.txt 준수, throttling(초당 호출 제한), 로그인/우회 없음(정통망법 침입·업무방해 회피).
     - **아웃링크 제공**(원 출처로 유입 = 상생 프레임).
     - **시간 박스**: 1~2회로 종료, 이후 시드는 창업자 직접 + UGC로만.
3. **대행자·UGC 전환 (주 엔진)**: 대행 거래·크라우드 제보가 검증가를 채우는 *내 소유* 플라이휠. 궤도 진입 시 크롤링 리스크 소멸 → 플랫폼이 데이터 저작권자.

## 4. 거래 플로우 (역경매 + 제3자 에스크로)

```
소비자: 품목·수량·희망가(수수료 포함) 요청  (역경매)
   ↓
대행자: 수락 / 현장 확인가 갱신
   ↓
결제: 소비자 → [제3자(공유) 에스크로] 예치   ← 플랫폼 자금 미보유
   ↓
대행자: 현장 결제 후 구매 → 배송
   ↓
소비자 수령 확인 → 에스크로 → 대행자 정산
```

- **에스크로**: 자체 PG/전자금융업 구축 안 함. **등록된 제3자 결제대금예치(에스크로)/안전결제** 사용(이니시스·나이스·토스페이먼츠 에스크로 또는 네이버페이·카카오페이 안전결제 등).
  - 전상법상 선결제 거래는 에스크로 또는 소비자피해보상보험 가입이 요구되므로(임계·예외 있음) **요건 충족이기도 함**.
  - 🔑 **합법성 핵심 조건**: 결제대금이 **플랫폼 명의 계좌를 거치면 안 됨**(PG/예치업 규제 부활). 돈은 `소비자 → 에스크로 → 대행자` 직행.
  - ⚠️ 일부 안전결제/PG 약관은 **구매대행·C2C 금지** → *허용하는 제공자* 선정 필요(미해결 §10).
- **정산 분리**: 현장 원가 / 대행 수수료 / (향후)중개 수수료를 시스템적으로 분리 발행 → 대행자 *사입(도소매)* 전환 방지·세무 방어. **결제 후 현장구매** 플로우를 시스템으로 강제(선사입 금지).

## 5. 면책·법적 구조

"모든 책임 당사자에게"는 **출발점은 맞지만 약관 한 줄로 완전 면책은 불가**(약관규제법 §7: 고의·중과실 면책 무효 / 소비자 권리는 강행규정). 면책은 *약관*이 아니라 *구조*로 확보한다:

| 레버 | 실행 |
|------|------|
| 고지 | 거래 화면마다 "플랫폼은 거래 당사자가 아님" 고지 (전상법 §20) |
| 자금 | 결제대금 플랫폼 미보유 (에스크로 직행) |
| 비관여 | 가격 *확정*·결제·배송에 직접 관여 안 함. **추정가는 "참고용"으로 격하**(표시 책임 최소화) |
| 표시 | 추정가 = 범위+라벨+출처, 확인가와 분리 |
| 분쟁 | "책임 없음"이 아니라 **분쟁조정 채널 제공**(신고·중재·제재). 방치 시 책임 |

- 미고지 / 소비자가 *플랫폼을 판매자로 오인* / 거래 *관여* / 피해 *방치* 시 → 연대책임(전상법 §20-2). 위 레버로 이를 차단.

## 7. 수익 (MVP 무수수료 → 향후)

- **MVP**: 중개수수료 0 (마찰↓·콜드스타트 윤활). 매출 0임을 인지 — 검증 전술이지 모델 아님.
- **향후 경로**: ① 제휴 어필리에이트(온라인 최저가 연동, 링크프라이스/쿠팡파트너스/네이버 쇼핑커넥트, 약관 내) ② 중개수수료 전환 ③ 대행자 상위노출/프리미엄.
- 무수수료라도 *중개자 책임은 면제되지 않음*(수수료 유무 무관).

## 8. MVP 범위

**In:** 앵커 1곳(여주 or 김포) · 지도(네이버맵, Canvas 렌더링+클러스터링) · 2층 가격(추정 참고 / 확인) · 역경매 요청 · 제3자 에스크로 · 창업자 직접 대행 · 니치 품목.
**Out (Phase 2+):** 전국 확장 · 다수 대행자 자동매칭 · LLM/OCR 자동 정제 파이프라인 · 벡터DB/RAG 자연어 검색 · 어필리에이트 정산 자동화 · 중개수수료.

## 9. 대행자 공급 (사업 성패 1순위)
