# 로보로브스키햄스터 핵심 행 확인표

- 무엇을 확인하나: 로보로브스키햄스터(`hamster-robo`, taxon `phodopus-roborovskii`)에만 해당하는 최소 규격 항목을 검수자가 출처로 채우고 서명하는 빈 표다. 형식은 `저빌-핵심행-확인표.md`·`기니피그-핵심행-확인표.md`를 따른다.
- **값 칸은 전부 비어 있다.** 이 표에는 수치·사실값이 없다(지어내지 않는다). 검수자가 출처를 직접 열어 값을 적고 서명한다.
- 출처 유형: 수의 출처 또는 사육 가이드 **2곳 이상**(서로 다른 도메인). 사료·건강 성격 항목은 수의 출처 포함 + 출처 2개 이상.
- **분리 유지 결정(Kenny §46):** 드워프 기준 공유 여부는 검수자 확인 뒤 결정, 지금은 분리 유지. 로보는 드워프 공유 프로필(`cp-hamster-dwarf` 등)을 그대로 쓰지 않고, 아래 행이 모두 확인되기 전까지 별도 항목으로 둔다.
- 현재 상태: `hamster-robo`는 PLANNED, `careProfileId`는 null, 검수 상태 DRAFT(AI_DRAFT)다. 이 표를 서명해도 바로 공개되지 않는다. 공개를 막는 것은 검수뿐이다.
- 법 관련 항목은 이 표에 없다(§47: 법 게이트 폐기).

## 확인 후 일어나는 일

- 값과 출처가 채워지고 서명된 행만 시드에 반영 대상이 된다. 비어 있거나 서명이 없는 행은 DRAFT로 남아 추천 영역에 들어가지 못한다.
- 이 표는 시드 JSON·코드를 바꾸지 않는다. 반영은 서명된 값이 들어온 뒤 별도 작업으로 한다.
