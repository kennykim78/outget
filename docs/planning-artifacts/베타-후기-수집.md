# WithSmall — 비공개 베타 후기 수집 (런칭 전 10개)

목표: 실 배포 전 비공개 테스트로 **실제 이용 후기 10개**를 받아 콜드스타트 홈 ②에 "베타 테스터 후기" 라벨로 건다. 임의 작성 없음. PRD US-026 `Testimonial` 규칙(승인 + `verifiedUsage`)을 그대로 따른다.

## 1. 참가자
- 10~15명 모집(탈락·미응답 감안). 구성 목표: 골든햄스터 처음 준비 4 · 골든햄스터 이미 키움 2 · 드워프햄스터 1 · 기니피그 1 · 저빌 1 · 사랑앵무 1 (Phase 0 ACTIVE는 골든햄스터뿐이므로 나머지는 PLANNED 화면과 "잘 모르겠어요" 흐름까지만 확인).
- 조건: 실제로 소동물·앵무새를 키우고 있거나 3개월 내 데려올 계획. 지인은 절반 이하(관계 편향).
- 보상: 소액(커피 쿠폰 수준). 후기 내용과 무관하게 지급한다고 먼저 밝힌다.

## 2. 테스트 과제 (L2까지 반드시 도달)
1. 홈에서 친구 선택 → 2질문(처음/이미, 가진 것) 답하기
2. "지금 필요한 것"에서 항목 하나 열어 규격 확인까지 해보기(내 케이지 치수 입력)
3. 구성안 3가지 중 하나 열어보기
4. 병원 목록 보기(지역 선택)
→ 완료 시 `verifiedUsage=true` 조건(체크 상태 또는 판정 이력)이 자동 충족된다.

## 3. 후기 질문 (3개, 자유 서술)
1. 준비하면서 **가장 헷갈렸던 것**이 WithSmall에서 어떻게 정리됐나요? (한 문장)
2. 실제로 **안 사도 되는 것**을 알게 됐거나, **규격을 확인**한 경험이 있었나요?
3. 아쉬웠던 점 하나.

카드에는 1·2번 답변 중 **문제 해결이 드러나는 한 문장**만 쓴다. 3번은 후기가 아니라 개선 백로그로 간다.

## 4. 승인 기준 (운영자)
- 실제 사용 흐름이 문장에 드러난다("케이지 치수를 넣으니…", "가진 걸 체크하니…").
- 감탄만 있는 문장("좋아요", "편해요")은 보류하고 구체화 요청 1회.
- 맞춤법·길이(≤80자)만 손본다. 뜻·강도는 바꾸지 않는다. 수정본은 작성자에게 확인받는다.
- 동물·상황 표기는 참가자가 고른 값 그대로(`animalTypeId`, `situation`).
- 게시 동의를 문장으로 받는다("홈 화면 후기 카드에 닉네임 없이 게시하는 데 동의합니다").
- **리뷰어 사진**(선택): 본인 동물·손·케이지 컷 1장. 얼굴이 식별되는 사진은 받지 않는다. 별도 동의 문장("사진을 후기 카드에 함께 게시하는 데 동의합니다") → `reviewerImageConsent=true`. 없으면 이니셜 원으로 표시.

## 5. 노출
- 라벨: 섹션 제목 "실제 이용 후기", 부제 "비공개 베타 테스터", 카드 칩 "이용 확인".
- 10개 확보 시 흐르는 레일 2줄(5+5, 역방향), 3~5개면 정지 레일, 0~2개면 사다리 규칙대로.
- 런칭 후 실제 사용자 후기가 3개 이상 승인되면 베타 후기와 섞어 최신순, 부제를 "이용이 확인된 분들만"으로 바꾼다.

## 6. 시드 파일 `server/seed/testimonials.json`
```json
[
  {
    "id": "t-001",
    "quote": "",
    "animalTypeId": "hamster-golden",
    "situation": "FIRST_TIME",
    "linkedAction": "CHECKLIST",
    "verifiedUsage": true,
    "source": "BETA_2026_10",
    "consentAt": "",
    "reviewerImage": null,
    "reviewerImageConsent": false,
    "status": "SUBMITTED"
  }
]
```
`quote`가 비어 있거나 `status≠APPROVED`면 렌더에서 제외. 10개 슬롯을 미리 만들어 두되, 채워지지 않은 슬롯은 절대 노출되지 않는다.

## 7. 일정 (권장)
- D-14 모집 · D-10~D-4 테스트(각 20분, 원격) · D-3 승인·동의 확인 · D-1 시드 반영 · D-0 런칭.
