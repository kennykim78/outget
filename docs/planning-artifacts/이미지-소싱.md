# WithSmall — 실사 이미지 소싱 규칙 · 장면 리스트 (Phase 0)

촬영 없이 **무료 라이선스 이미지**만 쓴다. 자동 수집 금지(Outget 불변식 유지) — 한 장씩 손으로 내려받고 출처를 기록한다.

## 1. 허용 라이선스와 조건
| 출처 | 라이선스 | 쓸 수 있나 | 조건 |
|---|---|---|---|
| Wikimedia Commons | CC0 / Public Domain | ○ | 출처 기록만 |
| Wikimedia Commons | CC BY 2.0~4.0 | ○ | **저작자·라이선스 표기 필수**(크레딧 페이지) |
| Wikimedia Commons | CC BY-SA | △ | 표기 + 자르기·합성한 결과물도 동일 라이선스로 공개해야 함 → **히어로·합성 이미지에는 쓰지 않음**, 원본 그대로 쓰는 카드에만 |
| Unsplash / Pexels / Pixabay | 각 사이트 자체 라이선스 | ○ | 표기 불필요(하되 기록은 남김). **"Unsplash+"·유료 표시 제외**. 상표·사람 얼굴·브랜드 로고가 보이는 컷 제외 |
| 판매자 상품 페이지·블로그·SNS | — | ✕ | 상품 이미지는 판매자 허가·제휴 API·직접 촬영만(PRD US-023) |
| AI 생성 이미지 | — | ✕ | 실사 자리에 넣지 않음. 마스코트만 우리 SVG |

기록 필드(PRD `imageLicense` 확장): `source(WIKIMEDIA|UNSPLASH|PEXELS|PIXABAY|OWN|SELLER|AFFILIATE)`, `license(CC0|CC_BY|CC_BY_SA|SITE_LICENSE|PERMISSION)`, `author`, `sourceUrl`, `downloadedAt`, `modified(bool)`. CC BY·CC BY-SA는 푸터 "사진 출처" 페이지(`/credits`)에 자동 나열.

## 2. 선별 기준
- **실제 사육 장면**이 우선(케이지 세팅, 쳇바퀴, 베딩, 급수, 병원). 동물 단독 '귀여운 컷'은 그룹 카드·후기 옆에만.
- 골든햄스터로 검색해서 **드워프·로보로브스키가 섞이지 않게** 확인(시리안 = *Mesocricetus auratus*). 잘못된 종 사진은 콘텐츠 신뢰를 바로 깎는다.
- 사진 속 용품이 우리 기준에 **어긋나면 쓰지 않는다**(작은 쳇바퀴, 살대형 쳇바퀴, 좁은 철망 케이지, 런닝볼). 카드 옆 문장이 "28cm 이상"인데 사진이 15cm 쳇바퀴면 안 된다.
- 흰 바탕 시스템이므로 **밝고 채도 낮은 컷**. 어두운 실내·플래시 컷 제외.
- 가로 4:3 또는 3:2, 원본 ≥1600px. 1:1 크롭 가능한 여백.

## 4. 운영 절차
1. 위 표 순서로 후보 2~3장씩 골라 `docs/assets/photos/_candidates/`에 원본 + `meta.json`(필드 §1) 저장.
2. 종·용품 기준 검수(경험 사육자 1인) → 통과분만 `docs/assets/photos/`로 이동, 파일명 `scene-01-cage-setup.jpg`.
3. 빌드 시 1600/800/400 3단 리사이즈 + WebP, `alt`는 장면 설명(동물명 포함).
4. `/credits` 페이지 자동 생성. CC BY 항목이 하나라도 있으면 푸터에 "사진 출처" 링크 노출.

## 5. 시안(캔버스)에서
플레이스홀더 라벨 `실사 사진 · <장면>`을 표의 # 번호로 바꿔 두면 소싱 후 교체가 1:1로 맞는다. 디자인 단계에서 실제 사진을 넣고 싶으면 Wikimedia CC0 컷만 임시로 쓴다.
