## 1. 동물·분류·프로필
- **AnimalType** `hamster-golden`(ACTIVE) + PLANNED 5종(드워프·저빌·기니피그·사랑앵무·왕관앵무 — 별칭만, 프로필 없음). 별칭에 "사막다람쥐→몽골리안저빌" 포함.
- **Taxon** *Mesocricetus auratus*: 동물보호법 6종 포함(유상 사적 분양 = 동물판매업 허가 대상), CITES 해당 없음. 법적 문구는 `TaxonLegalRevision`으로 개정 추적.
- **CareProfile** `cp-hamster-syrian`: 단독 사육 · 야행성 · 성체 15~18cm · 18~26℃ · 40~60% · 수명 2~3년. 케어 노트 3줄(단독·야행·굴).

## 4. 호환 규칙(CompatibilityRule) 3
- **쳇바퀴 × 케이지**: `지름+4 ≤ 높이` 아니면 BELOW_MIN / `지름+15 ≤ 높이` 아니면 CHECK(베딩 15cm 고려) / 걸이형은 철망에서만.
- **급수기 × 케이지**: 걸이형은 철망에서만, 리빙박스는 스탠드·그릇 안내(CHECK).
- **터널 × 케이지**: 내경 6cm 미만 BELOW_MIN.
→ 시안의 "내 케이지 60×40×35 리빙박스 + 30cm 쳇바퀴" = 34 ≤ 35 통과, 45 > 35 → **△ 확인 필요**(베딩 낮추기 안내). 시안 문구를 이 결과로 맞출 것.

## 9. 병원 슬롯 5 (`vet-clinics.json`, 서울 마포구)
전화로 "햄스터 진료 가능·야간·응급" 확인한 것만 `verification.status=VERIFIED`. 홈페이지 문구만으로 확인 처리 금지. 미확인은 "제보됨 · 확인 전"으로만 노출.

## 10. 콘텐츠 린트(빌드 게이트)
금지어: 괜찮다 · 안전하다 · 최저가 · 판매순 · 베스트 · 정확도 · 전문가 N명 · 회원가입. 숫자에 단위 필수(`28cm`, `60×40cm`). `why`는 2문장 이내, `caution`은 1문장. AI_DRAFT 레코드는 VERIFIED로 승격 불가(검수자 handle 필수).
