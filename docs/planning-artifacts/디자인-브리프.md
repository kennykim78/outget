캔버스에서 새 화면을 요청하거나 기존 아트보드를 고칠 때, 아래 블록을 요청 앞에 붙여 넣는다. 한 번에 화면 하나, 결정 하나. UX 기획 v2.4(상하 흐름·레일·레이어) · 디자인 시스템 토큰 v2.0(`docs/design/tokens.json` 2.0.0, 순백 + 청록) 기준. 시안(R3·R4·R5)과 구현이 이 브리프의 근거다.

- 디자인 시스템 "WithSmall Design System"(캔버스에 설치됨)의 토큰만 쓴다. 새 색·새 라운드·새 폰트 크기를 만들지 않는다.

- 구조는 상하 흐름 + 가로 레일. 좌측 내비·고정 사이드 패널·2열 관리자 레이아웃 금지(PC 포함). 모든 폭에서 섹션 순서 동일. 홈 구성은 아래 「홈은 둘뿐」 항목.

- 도구 화면(체크리스트·용품 상세·규격 확인·상품 상세·동물 선택)은 페이지가 아니라 레이어다. ≤767 바텀시트 / 768~1023 센터 모달 600 / ≥1024 센터 모달 720 — **용품·상품 상세 포함 전부 같은 모달(우측 드로어 480 폐기)**. 모달은 제목행 + ✕ + 구분선 고정, 본문은 최대 높이 안에서 스크롤, 하단 주 버튼 고정. 레이어 뒤 페이지는 흐리게 그대로 보인다.
- 상단 글로벌 헤더: 로고 · 메뉴 「준비물 · 크기 확인 · 병원」 · CTA 자리 = 선택 상태 칩(미선택 「친구 선택하기」 채운 버튼 / 선택 시 동물 이름만, 마스코트·▾ 없음). **모바일 하단 탭바 없음** — ≤767은 로고 + 「메뉴」 단추, 탭하면 헤더 아래 패널에 메뉴 3 + 칩(공개 내비게이션: Esc로 닫고 단추로 포커스 복귀, 포커스 트랩 없음). 소개·문의 페이지 없음. 푸터는 최소: 로고·한 줄 소개·개인정보 처리방침·사진 출처·의료 판단 고지·©. 헤더 높이 56, 그림자 없음, line 1px.
- 카드는 TypeCard·BundleCard·ProductCard·VetCard·VerdictCard 다섯 곳에만. 그림자 없음(바텀시트·고정 액션바만 shadow-sheet). 레일 카드는 모바일에서 1.3개 peek, PC에서 4~5개+화살표.
- 제휴 하단 고지(note-f): 제휴 링크가 보이는 화면(L4·L7·/supplies/{item}/{type}, 피드를 켠 빌드의 몰 상품 레일이 있는 선택 홈)에만, 페이지 하단 푸터 © 바로 위에 원문 한 문장, 접힘 없음. 제휴 링크가 없으면 고지도 없다. 상인 링크가 없으면 비활성 「상인 링크 준비 중」 버튼.
- 상품 카드 구성 고정: 이미지 1:1 → 상품명 1줄 → 규격 한 줄("30cm · 무소음") → `○ 기준 충족` → ♥(숫자는 10 이상일 때만). 가격·판매처·"구매"·"최저가"·"베스트" 없음. 이미지 없는 상품은 용품 아이콘 타일(bg-100)로 대체하고 "이미지 준비 중"이라 쓴다. 실제 상품 사진을 임의로 그리지 않는다 — 플레이스홀더에는 `상품 이미지(운영자 제공)` 라벨.
- 몰 상품(피드) 카드는 위 구성과 따로다(11/23 합의안, 피드를 켠 빌드에서만 — 기본 꺼짐): 몰 상품명·규격 표기·중립 배지 「표기 규격 통과」(L4만 「규격 확인 필요」 △ 가능)·가격과 확인일(확인 72시간 안에서만)·「제휴 링크」·몰 버튼 「쿠팡에서 보기」. `○ 기준 충족`·♥ 없음. 홈에서는 「몰에 올라온 상품」 레일(머리에 제휴 고지 1회, 가격을 보일 때는 가격 안내 1줄), L4에서는 상품 카드 뒤 「몰 검색 결과」 블록(블록 안 제휴 고지 1회).
- 마스코트는 동물 선택 레이어·빈 상태·완료 축하에만(R3·R4 시안의 홈 히어로·선택 홈 헤더에는 마스코트가 없다). 판정·규격 표·병원·법적 안내·상품 카드에는 절대 넣지 않는다. **그 밖의 이미지 자리는 전부 사진**(케이지 세팅·쳇바퀴 설치·치수 재기·병원 등 실제 사육 장면). 아이콘·이모지·일러스트로 대체하지 않는다. **홈 사진은 생성 이미지를 임시로 쓴다(D14, Kenny 2026-11-14): 사용권 문제가 없는 생성분만, 「생성 이미지 · 임시」로 표시하고 실사진 확보 시 교체.** 생성 이미지가 아직 없는 자리는 회색 타일에 `사진 · <장면>` 라벨.
- 홈은 둘뿐.
  **미선택 홈**: ① 히어로(큰 한 문장 + 부제 + 선택 바 1 — 입력이 아니라 링크) ② 「처음 준비, 여기서 시작해요」 시작 카드 3(꼭 필요한 것 먼저 · 크기 확인 · 구성안; PC 3열 / 모바일 가로 레일) ③ 설명 섹션(구현됨 U3c~U3e) — 「지금 필요 없는 것도 알려 드려요」 2열 · 큰 숫자(최소 규격, 시드 값) · 「함께 살 집」 노출 타입 카드 · 「진료하는 병원만」(진료 동물 집계, 병원 이름·지도 그림 없음), 데이터 없는 부분은 숨김 ④ 하단 CTA(문장 좌·버튼 우). 후기·소개 슬라이드·기능 칩·마퀴 없음. 저장 유도 없음.
  **선택 홈**: 컨텍스트 헤더(눈썹 「함께하는 친구」 + 동물명 + [바꾸기], 섹션 아님) → 지금 필요한 것(요약 카드 + 남은 필수 항목 카드, 채운 CTA 1; L3 전에는 「필수 준비를 먼저 확인해요」·숫자 없음) → 나중에 필요한 것(NOT_NOW 이름 + 이유) → 처음 준비한다면(구성안 레일) → {용품} 규격 확인(큰 숫자 + 단위) → 기준에 맞는 준비물(상품 레일) → 몰에 올라온 상품(몰 상품 레일 — 피드를 켠 빌드에서 카드가 있을 때만) → {동물} 진료하는 병원(없으면 「확인된 병원이 아직 없어요」) → 저장 안내(텍스트 링크). 데이터가 없는 섹션은 그리지 않는다.
  한 섹션에 두 가지 내용을 넣지 않는다(규격 확인의 텍스트·사진 2분할은 한 내용). **금지: 그룹 카드(소동물·앵무새 그룹 단위)·카테고리 격자·스텝 번호 카드·특징 2×2 격자. 허용(D4, Kenny 2026-11-14): 미선택 홈의 노출 타입 카드 — 노출(ACTIVE) 타입만, PLANNED 제외, 카드 → 타입 홈.** 후기는 홈에 두지 않고 L5 결과 아래 「크기 확인에 도움 된 점」 1건(선과 텍스트, 카드·별점 없음, 현재 화면에 맞는 후기가 0건이면 제목·선·여백까지 비노출)으로만.
- 저장(가입) 유도는 2곳뿐: 선택 홈 저장 안내의 텍스트 링크(「이메일로 저장하기」), L2 푸터 '지금 준비 상태를 저장해 둘까요?'. 콜드스타트 홈·히어로·헤더에는 넣지 않는다. 팝업·버튼 금지. L8 시트는 이메일 입력 1개 + [저장 링크 받기] + [나중에 할게요].
- 화면당 채워진 CTA 하나(brand). 나머지는 아웃라인. 터치 타깃 44px.
- 단일 라이트 테마. 다크 테마 요청·생성 금지. 아트보드는 390(모바일)과 1280(데스크톱) 두 폭.
- 카피: 존댓말, 짧게. 쓰지 않는 말 — 구매·판매·거래·세트·최저가·판매순·베스트·추천 상품·괜찮아요·안전해요·정확도 %·전문가 N명·회원가입·로그인하면 더·지금 가입·N만 사용자.
  고정 문구 — 선택 홈 섹션 제목 "지금 필요한 것 / 나중에 필요한 것 / 처음 준비한다면 / {용품} 규격 확인 / 기준에 맞는 준비물 / {동물} 진료하는 병원"(몰 상품 레일은 "몰에 올라온 상품"), 미선택 홈 "처음 준비, 여기서 시작해요" / 헤더 메뉴 "준비물 / 크기 확인 / 병원" / 푸터 고지 "의료 판단을 대신하지 않아요" / 판정 단어 "기준 충족 · 확인 필요 · 미달 · 기준 없음 · 입력 필요" / "지금은 필요 없어요"+이유 / "이 기기에만 저장돼요" / "후보 안내일 뿐, 종을 확정하지 않아요" / "참고 범위예요. 실제 가격은 판매처마다 달라요" / 상품엔 "기준 충족", "이 조건으로 찾기"만.
- 실제 콘텐츠만: 골든햄스터, 시드 기준 쳇바퀴 최소 27cm·권장 30cm, 케이지 최소 바닥 100×50cm(시드 DRAFT, 검수 전 — 화면 숫자는 시드·엔진 값만, 시안 값 고정 금지), 예시 입력 내 케이지 60×40×35cm 리빙박스, 구성안 실속 6개 7만 원대·균형 8개 12만 원대·기존 활용 새로 4개(구성안 값 확인 필요). 로렘입숨·가짜 통계·가짜 리뷰·가짜 브랜드 로고 금지.

## 수정 요청 방식
캔버스 코멘트나 채팅에 "홈 1280의 ④ 레일만: 카드 폭 200→180, 5개→6개, 나머지는 그대로" 식으로 **아트보드 + 섹션 + 바꿀 것 + 유지할 것**을 명시한다. "예쁘게", "현대적으로", "쇼핑몰처럼" 같은 형용사 요청은 AI 기본값으로 회귀하므로 쓰지 않는다.

## 검수 체크(디자인 받은 뒤)
1. 토큰 밖의 색·크기·라운드가 있는가 → 되돌린다.
2. 좌측 내비·고정 패널·나란히 놓인 섹션이 생겼는가(특히 1280) → 상하 흐름으로 되돌린다.
3. 상품이 화면의 절반 이상이거나 격자로 깔렸는가 → 레일 1줄, 카드 ≤ 200으로 줄인다.
4. 상품 카드에 가격·판매처·"구매"·마스코트가 있는가 → 뺀다. `○ 기준 충족`이 빠졌는가 → 넣는다. (몰 상품(피드) 카드는 예외 — 가격·확인일·몰 버튼이 있고 `○ 기준 충족`이 없다. "구매"·마스코트는 똑같이 없다.)
5. 판정·규격·병원 화면에 마스코트가 들어갔는가 → 뺀다.
6. 상태가 색으로만 표시된 곳이 있는가 → 아이콘·문구 추가.
7. 도구 화면이 페이지로 그려졌는가 → 레이어(바텀시트/모달 720·600)로, 뒤 페이지가 보이게. 우측 드로어가 있으면 모달로 되돌린다.
8. 금지 단어가 카피에 있는가 → 고정 문구로 교체.
9. 설명·기능 자리에 아이콘·일러스트·마스코트가 들어갔는가 → 사진(또는 생성 이미지 임시 표시, 없으면 라벨 타일)으로.
10. 저장 유도가 2곳을 넘거나 버튼·팝업이 됐는가 → 되돌린다. 후기가 홈에 있거나, 별점·점수·'좋아요!' 류 짧은 감탄이 있거나, 0건인데 빈 영역·작성 유도가 남았는가 → 되돌린다(후기는 L5 결과 아래, 문제 해결 문장 1건).
11. 홈 한 섹션에 두 가지 내용이 섞였는가, 하단 탭바·그룹 카드·상태 글리프 규칙(○ △ ✕ — ?, 「나중에」는 단어만) 위반이 있는가 → 되돌린다.
