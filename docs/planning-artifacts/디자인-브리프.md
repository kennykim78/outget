# WithSmall — 클로드 디자인 작업 브리프 v2.3.1 (Phase 0)

캔버스에서 새 화면을 요청하거나 기존 아트보드를 고칠 때, 아래 블록을 요청 앞에 붙여 넣는다. 한 번에 화면 하나, 결정 하나. UX 기획 v2.0(상하 흐름·레일·레이어) 기준.

## 붙여 넣는 블록 (공통)

```
[WithSmall 디자인 규칙 v2.0 — 반드시 적용]
- 디자인 시스템 "WithSmall Design System"(캔버스에 설치됨)의 토큰만 쓴다. 새 색·새 라운드·새 폰트 크기를 만들지 않는다.
  바탕 bg-000(#ffffff 순백), 따뜻한 밴드 bg-100(#f7f4ef — 요약 블록·시트 헤더·히어로 뒤 얕은 밴드만), 카드 surface(#fff)+line(#e9e3da) 1px, 텍스트 ink(#2f2b27), 보조 ink-muted(#6e675f),
  브랜드 brand(#7cc8b1, 텍스트는 on-brand #1d2a26), 링크 brand-text(#2c7a66). 라운드: 입력 8 / 버튼·카드 14 / 시트·요약 20 / 칩 999.
- 상태색은 브랜드와 분리, 파스텔화 금지, 항상 아이콘+색+문구 3중:
  ✓ 준비완료 #227a4a · ! 먼저 준비 #c94a2f · △ 확인 필요 #a86300 · ○ 나중에 #8a8279 · ✕ 최소 미달 #a8231a
- 폰트 Pretendard 하나. 크기: 히어로 32/800, 페이지 제목 24/700, 섹션 18/700, 본문 16/400, 메타 13/400, 규격 숫자 18/700(tabular), 강조 숫자 28/800.
  규격 숫자("28cm", "60×40cm")는 문장에서 가장 강한 요소. 단위는 숫자에 붙여 쓴다.
- 구조는 상하 흐름 + 가로 레일. 좌측 내비·고정 사이드 패널·2열 관리자 레이아웃 금지(PC 포함). 모든 폭에서 섹션 순서 동일:
  ① 히어로(마스코트+한 줄+동물 선택) ② 지금 필요한 것(칩 레일) ③ 처음 준비한다면(구성안 카드) ④ 기준에 맞는 준비물(상품 카드) ⑤ 우리 동네 병원(병원 카드).
  시각 비중 고정: 캐릭터 > 구성안 > 용품 > 상품. 상품 카드 폭 ≤ 200, 상품이 화면의 절반을 넘지 않는다.
- 도구 화면(체크리스트·용품 상세·규격 확인·상품 상세·동물 선택)은 페이지가 아니라 레이어다. ≤767 바텀시트 / 768~1023 센터 모달 600 / ≥1024 센터 모달 720(용품·상품 상세는 우측 드로어 480). 레이어 뒤 페이지는 흐리게 그대로 보인다.
- 상단 글로벌 헤더: 로고 · 동물 칩(🐹 골든햄스터 ▾) · (PC) 용품 찾기 · 병원. 모바일은 하단 탭 3개(홈·용품·병원). 헤더 높이 56, 그림자 없음, line 1px.
- 카드는 TypeCard·BundleCard·ProductCard·VetCard·VerdictCard 다섯 곳에만. 그림자 없음(바텀시트·고정 액션바만 shadow-sheet). 레일 카드는 모바일에서 1.3개 peek, PC에서 4~5개+화살표.
- 상품 카드 구성 고정: 이미지 1:1 → 상품명 1줄 → 규격 한 줄("30cm · 무소음") → `✓ 기준 충족` → ♥(숫자는 10 이상일 때만). 가격·판매처·"구매"·"최저가"·"베스트" 없음. 이미지 없는 상품은 용품 아이콘 타일(bg-100)로 대체하고 "이미지 준비 중"이라 쓴다. 실제 상품 사진을 임의로 그리지 않는다 — 플레이스홀더에는 `상품 이미지(운영자 제공)` 라벨.
- 마스코트는 히어로·동물 선택 레이어·빈 상태·완료 축하에만. 판정·규격 표·병원·법적 안내·상품 카드에는 절대 넣지 않는다. **그 밖의 이미지 자리는 전부 실사 사진**(케이지 세팅·쳇바퀴 설치·치수 재기·병원 등 실제 사육 장면). 아이콘·이모지·일러스트로 대체하지 않는다. 시안에서는 회색 타일에 `실사 사진 · <장면>` 라벨을 쓰고 사진을 생성하지 않는다.
- 홈은 둘뿐. 미선택 홈 5섹션: 친구 선택 → 실제 이용 후기(흐르는 레일 2줄 역방향, 호버 정지. ReviewCard: 따옴표 문장 16/600 + 리뷰어 사진 40px 원형(동의분, 없으면 회색 이니셜 원) + '골든햄스터 · 처음 준비' + '이용 확인' 칩 + 행동 링크. 별점·점수 없음. 0개면 섹션 자체 없음) → WithSmall 소개(슬라이드 4 = 지금 필요한 것·규격 판정·구성안·동네 병원, 한 화면 한 내용: 모바일 세로 슬라이드, PC 좌 sticky 사진 + 우 항목 리스트에서 활성 1개만 펼침) → 시작 배너. 미선택 홈은 4섹션. 히어로 CTA 아래 기능 칩 4개 한 줄(아웃라인, 34px)이 가로 요약 — 별도 '주요 기능' 섹션은 만들지 않는다. 선택 홈 5섹션: 지금 필요한 것 → 처음 준비한다면 → 기준에 맞는 준비물 → 동네 병원 → 저장 배너. 선택 홈 상단은 컨텍스트 헤더(마스코트 96 + 동물명 + 상태 한 줄 + [친구 바꾸기])이며 섹션이 아니다. L3(2질문) 전 상태를 그릴 때는 '필수 준비를 먼저 확인해요'로, 숫자 없이. 한 섹션에 두 가지 내용을 넣지 않는다. 그룹 카드·카테고리 격자·스텝 번호 카드·특징 2×2 격자 금지.
- 저장(가입) 유도는 2곳뿐: 선택 홈 저장 밴드의 보조 텍스트 링크, L2 푸터 '지금 준비 상태를 저장해 둘까요?'. 콜드스타트 홈·히어로·헤더에는 넣지 않는다. 팝업·버튼 금지. L8 시트는 이메일 입력 1개 + [인증 메일 보내기] + [나중에 할게요].
- 화면당 채워진 CTA 하나(brand). 나머지는 아웃라인. 터치 타깃 44px.
- 단일 라이트 테마. 다크 테마 요청·생성 금지. 아트보드는 390(모바일)과 1280(데스크톱) 두 폭.
- 카피: 존댓말, 짧게. 쓰지 않는 말 — 구매·판매·거래·세트·최저가·판매순·베스트·추천 상품·괜찮아요·안전해요·정확도 %·전문가 N명·회원가입·로그인하면 더·지금 가입·N만 사용자.
  고정 문구 — 섹션 제목 "지금 필요한 것 / 처음 준비한다면 / 기준에 맞는 준비물 / 우리 동네 병원"(미선택 시 "요즘 많이 찾는 준비") / "지금은 필요 없어요"+이유 / "이 기기에만 저장돼요" / "후보 안내일 뿐, 종을 확정하지 않아요" / "참고 범위예요. 실제 가격은 판매처마다 달라요" / 상품엔 "기준 충족", "이 조건으로 찾기"만.
- 실제 콘텐츠만: 골든햄스터, 쳇바퀴 최소 28cm·권장 30cm, 케이지 60×40cm, 내 케이지 60×40×35cm 리빙박스, 구성안 실속 6개 7만 원대·균형 8개 12만 원대·기존 활용 새로 4개. 로렘입숨·가짜 통계·가짜 리뷰·가짜 브랜드 로고 금지.
- 금지: 그라데이션, 좌측 컬러바 카드, 이모지 장식(카테고리 글리프 🌿☁♻ 제외), 배지 과다, 상품몰식 썸네일 그리드(2열 이상 격자), 가짜 상태바, 100vh 히어로, 알약 남발, 히어로 배너 캐러셀, 할인 스티커.
[끝]
```

## 수정 요청 방식
캔버스 코멘트나 채팅에 "홈 1280의 ④ 레일만: 카드 폭 200→180, 5개→6개, 나머지는 그대로" 식으로 **아트보드 + 섹션 + 바꿀 것 + 유지할 것**을 명시한다. "예쁘게", "현대적으로", "쇼핑몰처럼" 같은 형용사 요청은 AI 기본값으로 회귀하므로 쓰지 않는다.

## 검수 체크(디자인 받은 뒤)
1. 토큰 밖의 색·크기·라운드가 있는가 → 되돌린다.
2. 좌측 내비·고정 패널·나란히 놓인 섹션이 생겼는가(특히 1280) → 상하 흐름으로 되돌린다.
3. 상품이 화면의 절반 이상이거나 격자로 깔렸는가 → 레일 1줄, 카드 ≤ 200으로 줄인다.
4. 상품 카드에 가격·판매처·"구매"·마스코트가 있는가 → 뺀다. `✓ 기준 충족`이 빠졌는가 → 넣는다.
5. 판정·규격·병원 화면에 마스코트가 들어갔는가 → 뺀다.
6. 상태가 색으로만 표시된 곳이 있는가 → 아이콘·문구 추가.
7. 도구 화면이 페이지로 그려졌는가 → 레이어(시트/모달/드로어)로, 뒤 페이지가 보이게.
8. 금지 단어가 카피에 있는가 → 고정 문구로 교체.
9. 설명·기능 자리에 아이콘·일러스트·마스코트가 들어갔는가 → 실사 라벨 타일로.
11. 홈 한 섹션에 두 가지 내용이 섞였는가, 5섹션을 넘는가 → 나누거나 뺀다.
10. 저장 유도가 2곳을 넘거나 버튼·팝업이 됐는가 → 되돌린다. 후기에 별점·점수·'좋아요!' 류 짧은 감탄이 있는가 → 문제 해결 문장으로.
