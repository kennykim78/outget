| 버전 | **v0.2** (당근형 양면 보드 전환) |
| 상태 | Draft — 기획(planning). 구현 미착수 |

> ⚠️ 법적 서술은 **리스크 분석**이며 법률 자문이 아니다. 통신판매중개·외부 안전결제·UGC 책임·세무는 진행 전 변호사·세무사 확인 필요(§9). 페이링크류 약관의 구매대행 허용은 **M1에서 서면 확답** 필수.

---

## 1. 비전 & 한 줄 정의

오프라인 아울렛 정보를 지도 위에 모으고, **현장 구매대행자와 구매자를 당근마켓처럼 리스트로 연결**하는 매칭 보드. 플랫폼은 *정보·매칭*만 제공하고 **결제·계약 당사자가 아니다.**

- **가치 제안:** "여주/김포 아울렛 특가를, 안 가도 대행으로." + "흩어진 할인 소식을 지도 한 장으로." + "대행자·구매자를 지도에서 바로 매칭."
- **차별 동력:** 데이터·기술이 아니라 **① 신뢰 가능한 대행자 공급 ② 매칭·분쟁 해결.**
- **데이터 철학:** 긁지 않는다. **창업자 시드 + 거래·UGC가 내 소유 데이터를 만든다**(플라이휠).

## 2. 문제 정의 & 기회

| 문제 | 기회 |
|---|---|
| 아울렛 할인 정보가 매장·SNS·카페에 파편화 | 지도 기반 **UGC 할인 소식** 집계(긁지 않고 제보로) |
| 물리적 접근성(여주/김포 등 외곽) | **현장 대행자 매칭**으로 거리 문제 해소 |
| C2C 구매대행의 신뢰·매칭 부재 | **양면 리스트 + 외부 안전결제 + 신고/제재**로 신뢰 제공 |

---

## 3. 목표 & 성공 지표 (MVP)

MVP는 **무수수료** → 매출 0. 성공지표는 **양면 매칭 검증 신호**다(플랫폼이 결제를 추적하지 않으므로 "완료 거래 수"는 직접 거래 분을 포함해 정확 측정 불가 → 매칭·요청 지표 중심).

| 구분 | 지표 | 비고 |
|---|---|---|
| 공급 | 등록 대행자 수(개인/전문) · 광고/일정 게시 수 | 공급 콜드스타트 해소 신호 |
| 수요 | 역경매 요청 수 · 할인소식 UGC 제보 수 | 수요·데이터 신호 |
| 매칭 | **채팅 매칭 성공 수** · **역경매 채택 수** | 핵심 전환 지표 |
| 안전결제 | 안전결제 **안내 노출/이용 클릭 수** | 직접거래는 미추적 → 클릭으로 대용 측정 |
| 신뢰 | 신고/블라인드 처리율 · 분쟁 신고 수 | 거버넌스 작동 신호 |
| 재방문 | 재방문율 / 재요청율 | 잔존 신호 |

> 정량 타깃은 창업자 시드 운영 1차 사이클 후 보정. **반증 조건:** 수요·정보는 있으나 대행 공급이 안 붙으면(🔴공급) 모델 재검토.

## 4. 타깃 사용자 & 페르소나

| 페르소나 | 핵심 니즈 | 핵심 두려움 |
|---|---|---|
| **구매자(요청자)** | 안 가고 특가 확보, 가격 투명성 | 사기·미배송·생각과 다른 물건 |
| **개인 대행자(비사업자)** | 쇼핑 동선 내 용돈벌이, 명확한 요청 | 헛걸음·정산 떼임·책임 전가·세무 |
| **전문 대행자(사업자)** | 반복 수익·광고 노출·일정 모집 | 분쟁·평판 |
| **소식 알림자(제보자)** | 기여·평판(뱃지) | 노력 대비 보상(무금전 → 뱃지로) |
| **운영자(창업자)** | 시드·매칭·분쟁 조정·거버넌스 | 연대책임(전상법 §20-2) |

MVP에서 **창업자 = 1호 대행자 + 1호 소식 알림자 + 운영자**(컨시어지·시드, §6 EPIC-S).

## 5. 범위 (Scope)

### In (MVP)
- 앵커 아울렛 **1곳**(여주 또는 김포 — 지역 비종속 설계)
- **양면 리스트 보드**(지도+리스트): 대행자 광고/일정 · 구매자 역경매 요청
- **UGC 할인 소식**(대행자·개인대행자·소식알림자 제보) + 대행자 **현장 확인가**
- **역경매 요청**(언제까지/무엇을/얼마에) → 대행자 채택
- **매칭 채팅** + **직접거래 / 외부 P2P 안전결제(페이링크류) 병행**(플랫폼 자금 미보유)
- **대행자 지위 구분**(개인 비사업자 / 전문 사업자 인증)
- **바운티 = 뱃지**(무금전 게이미피케이션) · 평판
- **공동대행 슬롯**(사입·세무 경고 + 결제후구매 안내 동반)
- **UGC 거버넌스**(신고→즉시 블라인드 임시조치, notice-and-takedown) · 통신판매중개 고지 · 분쟁 신고 채널
- **창업자 시드 운영**(수동 큐레이션 + 현장 출동)

### Out (Phase 2+)
전국 확장 · 다수 대행자 자동매칭 알고리즘 · LLM/OCR 자동 정제 · 벡터DB/RAG 검색 · 어필리에이트 정산 · **중개수수료** · 플랫폼 내장 에스크로/정산 · 매장 매니저 직접 피드(**공식 입점 형태로만** 재검토).

### Non-goals (명시적 비목표 — 컴플라이언스 방어선)
- **결제 대금을 중개·보관하지 않는다.** 자금은 플랫폼을 경유하지 않음(외부 안전결제 or 직접거래).
- **플랫폼은 가격을 *주장*하지 않는다.** 가격·할인 정보는 전부 UGC(미검증 제보) 또는 대행자 현장 확인가.
- **상품 카탈로그가 아니다.** 품목 DB를 플랫폼이 완비하지 않음 — 사람(대행자·구매자) 리스트가 1차.
- **크롤링하지 않는다**(자동 수집). 시드는 창업자 수동 큐레이션(사실/직접촬영)만.
- **직접거래의 계약 성사·이행은 추적하지 않는다**(외부 안전결제 거래만 상태 추적). 단, 통신판매중개 **최소 의무**(고지·신원정보 제공·분쟁 신고 채널)는 유지 — 완전 블라인드 아님.

## 6. 기능 요구사항 (FR) — 에픽

### EPIC A — 지도 & 양면 리스트 보드
- **FR-A1** 지도/리스트 토글로 **① 대행자 광고 ② 구매자 역경매 요청 ③ 할인 소식**을 본다. 밀집 시 클러스터링.
- **FR-A2** 앵커 아울렛·주변을 중심으로 핀·일정·요청이 위치 기반으로 표시된다.
- **FR-A3** 필터: 브랜드/카테고리/지역/일정/지위(개인·전문)/키워드(플랫폼 보유 데이터 한정, 외부 크롤링 없음).
- **FR-A4** 위치 권한 허용 시 현위치 기준 거리. **실시간 GPS 추적/공유 없음**(NFR-C6).

### EPIC B — 대행자 공급(광고·일정·지위)
- **FR-B1** 대행자는 프로필에 **광고 소개 · 활동 지역 · 출동 일정**(예: "토요일 여주 출동")을 게시. 위치는 **동·지역 단위 텍스트**(실시간 좌표 금지).
- **FR-B2** 가입/프로필 생성 시 **[개인 대행자(비사업자)] / [전문 대행자(사업자등록증 인증)]** 중 선택.
- **FR-B3** 개인 대행자에게 **"지속·반복 영리 활동 시 사업자 등록 의무가 발생할 수 있습니다"** 상시 고지.
- **FR-B4** 전문 대행자 경로는 **상호·사업자번호·연락처를 수집·표시**(전상법 통신판매중개의뢰자 정보 제공 의무 대응).
- **FR-B5** 구매자는 대행자 광고/일정을 보고 **채팅으로 매칭 요청**.

### EPIC C — 구매자 역경매 요청
- **FR-C1** 구매자는 **"언제까지 / 무엇을(옵션 색·사이즈) / 얼마에(대행료 포함 희망가)"** 요청을 게시.
- **FR-C2** 요청은 보드/지도에 노출되고, 대행자가 **채택(수락)/현장 확인가 제시/거절**.
- **FR-C3** 요청 상태(대기·채택·매칭·진행·종료) 추적(외부 안전결제 거래는 상세 추적, 직접거래는 매칭까지).
- **FR-C4** 채택·확인가 제시 시 구매자에게 알림.

### EPIC D — 매칭 채팅 & 결제 선택
- **FR-D1** 매칭 시 **인앱 채팅** 제공(증빙·고지·신고 동선의 허브).
- **FR-D2** 거래 방식은 **① 직접거래 ② 외부 P2P 안전결제(페이링크류)** 중 선택. **플랫폼 자금 미보유**.
- **FR-D3** **안전결제 권장 넛지** + 직접거래 선택 시 **사기 경고**("외부 채널 유도·선입금 주의, 공식 안전결제 이용 권장"). 단, 플랫폼이 외부 링크의 안전성을 *검증·보증하지 않음*을 명시(검증기 미도입).
- **FR-D4** 채팅 화면에 통신판매중개 고지(FR-G1)·신고 버튼(FR-G2) 상시 노출.

### EPIC E — 아울렛 할인 소식(UGC) & 현장 확인가
- **FR-E1** 대행자·개인대행자·소식알림자는 **할인 소식**을 게시: 품목/브랜드 · **할인율(%) 또는 할인가** · 정가(**Optional**) · **출처** · 사진(**직접 촬영분만**).
- **FR-E2** 정가 미입력 시 화면에 **`[기준가 미확인 · 사용자 제보가]`** 라벨 자동 부착(표시광고법 완화). 전체 가격을 단정 표기하지 않고 **할인 부분 중심**으로 노출.
- **FR-E3** 모든 할인 소식에 **출처·작성자·시각·"미검증 제보"** 표기 + **신고 버튼**(EPIC G).
- **FR-E4** **현장 확인가**(대행자 실측)는 미검증 제보와 **시각·문구로 명확히 구분**("현장 확인가 ✅ · OO 대행자 · YYYY-MM-DD").
- **FR-E5** 데이터는 출처와 함께 *내 소유*로 축적(크롤링 대체 플라이휠).

### EPIC F — 바운티(뱃지) & 평판
- **FR-F1** 구매자는 "현장 확인 미션"(예: "여주 나이키 270 재고 사진")을 **무금전**으로 등록.
- **FR-F2** 수행자가 사진/정보 제출 시 **금전 대신 뱃지/평판 점수** 부여(PG·선불수단 리스크 회피).
- **FR-F3** 사진 신뢰 보강: 촬영 시각·(가능 시) 위치 메타로 재탕·도용 완화.
- **FR-F4** 뱃지·평판은 프로필에 노출(대행자 신뢰 시그널).

### EPIC G — 신뢰·분쟁·고지·UGC 거버넌스
- **FR-G1** 거래/요청/소식/채팅 화면에 **"Outget은 통신판매중개자이며 거래 당사자가 아님"** 상시 고지(전상법 §20).
- **FR-G2** 모든 UGC에 **신고 버튼**. 저작권 침해·허위·사기 신고 시 **즉시 블라인드(임시조치)** → 처리.
- **FR-G3** **notice-and-takedown** 프로세스를 약관에 명시(OSP 면책). **블라인드 후 이의/재게시 절차** 포함(과잉 임시조치 분쟁 방지).
- **FR-G4** 분쟁 신고 채널 + 운영자(창업자) 중재·제재(경고/정지). *방치하지 않음*(방치 시 연대책임).
- **FR-G5** 요청 시 **거래 상대 신원정보 제공**(통신판매중개자 의무).

### EPIC I — 공동대행 슬롯
- **FR-I1** 대행자는 출동 일정에 **공동대행 슬롯**(예: "토요일 여주, 5자리")을 개설.
- **FR-I2** 슬롯 개설/참여 시 **경고 모달**: "대량구매는 *사입(도소매)*으로 간주되어 **세무 리스크**가 있습니다. 각 요청 건은 **요청 접수 후 구매**하세요(선사입 금지)." 동의 후 진행.
- **FR-I3** (직접거래라 시스템 강제는 불가) 결제후구매를 **안내·고지**로 방어.

### EPIC S — 창업자 시드 & 운영(컨시어지)
- **FR-S1** 창업자는 **소식 알림자**로 공식 채널(카톡채널·인스타) 행사 **사실(텍스트)**을 손으로 큐레이션 업로드(저작권 무이슈). 이미지는 **직접 촬영분만**.
- **FR-S2** 오픈 첫 **2~4주** 주말 여주/김포 **현장 상주** → 매대 사진·할인율로 초기 정보층을 두껍게.
- **FR-S3** 창업자 **1호 대행자**로 역경매 채택·매칭을 직접 수행(분쟁·정산·플로우 학습).

## 7. 비기능 요구사항 (NFR)

| 영역 | 요구 |
|---|---|

## 8. 데이터 모델 개요 (논리)

> 스택 미정. 저장 데이터는 전부 *내 소유*(창업자 시드/거래/UGC) — 긁어온 원문은 저장 안 함.

- **User** — role: 구매자 / 개인대행자 / 전문대행자 / 소식알림자 / 운영자 (겸직 가능)
- **AgentProfile** — 지위(개인/전문), 사업자정보(전문), 활동지역, 출동일정(텍스트), 광고, 평판/뱃지
- **Request**(역경매) — 구매자·품목·옵션·희망가(대행료 포함)·기한·상태
- **Match** — Request↔Agent 매칭, 채팅스레드, 거래방식(직접/안전결제), 상태
- **DiscountPost**(UGC 할인소식) — 품목/브랜드·할인율 or 할인가·정가(opt)·출처·사진(직접촬영)·작성자·시각·미검증라벨
- **VerifiedPrice**(현장 확인가) — 품목·단일가·대행자·확인일(책임 귀속)
- **Bounty** — 미션·요청자·상태 / **BountySubmission** — 사진·시각·수행자·부여 뱃지
- **Badge/Reputation** — 사용자 평판 시그널
- **GroupSlot**(공동대행) — 대행자·일정·정원·경고동의
- **Report** — 대상 UGC·사유·상태(블라인드/처리/이의) / **Dispute** — 매칭·사유·증빙·처리

## 9. 가정 · 제약 · 미해결 (M1 게이트)

**가정**
- 니치 품목(온라인 품절/단독/한정)에서 대행료+배송 감안해도 가치 있음.
- 창업자 시드 2~4주로 정보·공급 콜드스타트 동시 해소 가능.
- 무금전 바운티(뱃지)로도 현장 데이터 참여가 일어남(무보상 제보 생태계 선례 존재).

**제약**
- 무크롤링·UGC 의존 → 정보 정확도는 제보 품질에 좌우(그래서 "미검증" 라벨·현장확인가 분리).
- 무수수료·자금 미보유 → MVP 매출 0 + "완료 거래" 정밀 측정 불가(직접거래 미추적).

**미해결 — 구현 전 해소(M1)**
1. **페이링크류 약관 서면 확답** — NHN KCP·토스페이먼츠 등에 "플랫폼은 결제 미관여, 유저가 개인간 심부름/대행 명목으로 페이링크를 채팅에서 공유·사용해도 약관상 문제없는지" **메일로 확답**. 결제 모듈은 *추상화*(제공자 교체 가능).
2. **법률 자문** — 통신판매중개자 책임/고지/신원정보, 개인 대행자 사업자등록 임계, UGC 표시광고·저작권 면책 경계, 공동대행 사입 세무.
3. **앵커 지역 최종 선정**(여주 vs 김포) · **스택 확정**(지도 SDK·저장소).
