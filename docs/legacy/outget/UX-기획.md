| 항목 | 값 |
|---|---|
| 제품 | Outget — 지도 기반 아울렛 구매대행 **매칭 보드**(당근형 양면) |
| 버전 | **v0.2** (당근형 양면 보드 전환) |
| 상태 | Draft — 기획 |
| 최종수정 | 2026-06-08 |
| 연계 | [PRD.md](PRD.md) v0.2 · [MVP_모델.md](../../../_archive/202610/MVP_모델.md) |
| 플랫폼 | **모바일 우선**(현장·이동 중). 반응형 웹/PWA 가정(스택 미정) |

> UX 두 축: **① 신뢰**(고지·안전결제 넛지·신고/블라인드·평판 뱃지) **② 정보 정직성**(UGC 미검증 라벨 ↔ 현장 확인가 분리). 당근마켓처럼 **사람(대행자·구매자) 리스트가 지도 위에** 보인다.

---

## 1. 디자인 원칙

1. **사람이 먼저** — 상품 카탈로그가 아니라 *대행자 광고·구매자 요청* 리스트가 1차 콘텐츠(당근형).
2. **추정 ≠ 확정 ≠ 보증** — UGC 할인소식("미검증 제보")과 현장 확인가를 색·아이콘·라벨로 분리. 플랫폼은 가격을 *주장*하지 않음.
3. **결제는 화면 밖** — 플랫폼은 매칭·채팅만. 직접/외부 안전결제 선택을 *안내*하되 **검증·보증하지 않음**.
4. **3탭 규칙** — 핵심 동선(요청 올리기, 대행자 채팅, 할인소식 보기)은 3탭 내.
5. **빈 화면 정직성** — 시드 전 빈 지도는 "곧 채워집니다/제보해 주세요"로 행동 유도(창업자 시드가 1차 해결, EPIC-S).

## 2. 정보구조 (IA) — 당근형 양면 보드

```
[지도 홈] ── 토글: ⟨대행자⟩ ⟨구매자 요청⟩ ⟨할인소식⟩
 ├─ 대행자 핀/카드 ──> 대행자 프로필(광고·지역·일정·평판) ──> [채팅]
 ├─ 구매자 요청 핀/카드 ──> 요청 상세 ──> [채택/채팅] (대행자 시점)
 └─ 할인소식 핀/카드 ──> 할인소식 상세(미검증 라벨/현장확인가) ──> [신고]
[글쓰기 +]
 ├─ 역경매 요청 올리기 (구매자)
 ├─ 대행 광고/일정 올리기 (대행자)
 ├─ 할인소식 올리기 (제보)
 └─ 바운티(현장확인 미션) 올리기 — 뱃지 보상
[채팅]
 └─ 매칭 스레드 ──> 거래방식 선택(직접/안전결제) · 고지 · 신고
[내 정보]
 ├─ 내 요청/광고/제보 · 평판 뱃지 · 거래·분쟁 기록
 └─ 지위 설정(개인/전문) · 고지/약관 · 분쟁 정책
```

**하단 탭(4):** `지도` · `글쓰기(+)` · `채팅` · `내 정보`

## 3. 핵심 화면 (와이어프레임)

### S1. 지도 홈 — 양면 토글
```
┌─────────────────────────────┐
│ 🔍 검색   ⟨대행자⟩⟨요청⟩⟨할인⟩ │  ← 콘텐츠 토글
├─────────────────────────────┤
│      🗺  지도 (클러스터)       │
│   🧑‍💼토요일 여주출동           │  ← 대행자 카드 핀
│        🙋"버버리 셔츠 5만"     │  ← 구매자 요청 핀
│   🏷️"나이키 30%↓ 떴어요"      │  ← 할인소식 핀
│  ┌───────────────────────┐  │
│  │ 🧑‍💼 OO 대행 [개인]      │  │  ← 바텀시트
│  │ 토 여주 출동 · ⭐뱃지 3   │  │
│  │ [프로필] [채팅]         │  │
│  └───────────────────────┘  │
├─────────────────────────────┤
│ 지도 |  ＋  | 채팅 | 내 정보   │
└─────────────────────────────┘
```

### S2. 할인소식 상세 — **정보 정직성(컴플라이언스)**
```
┌─────────────────────────────┐
│ ← 나이키 에어맥스             │
├─────────────────────────────┤
│  [현장 확인가 ✅] 39,000원    │  ← 있으면 최상단·강조(초록)
│  OO 대행자 · 2026-06-07 확인  │
│  ─────────────────────────  │
│  🏷️ 30% 할인 떴어요           │  ← UGC 할인소식(할인 부분 중심)
│  [기준가 미확인·사용자 제보가] │  ← 정가 미입력 시 자동 라벨(회색)
│  출처: 매장 현장 / 제보자 닉   │
│  📷 (제보자 직접 촬영)         │
│  2026-06-07 · 미검증 제보     │
│  [🚩 신고]                    │
├─────────────────────────────┤
│  ⓘ Outget은 통신판매중개자이며 │  ← 상시 고지
│     거래 당사자가 아닙니다     │
└─────────────────────────────┘
```
- 정가 입력 시: `정가 55,000 → 약 39,000(30%↓)` 범위/근거 표기.
- 확인가 없을 때 상단: "아직 현장 확인가 없음 · 대행 매칭 시 확인됩니다".

### S3. 대행자 프로필(광고·지위·일정·평판)
```
┌─────────────────────────────┐
│ ← OO 대행   [개인 대행자]      │  ← 지위 뱃지(개인/전문)
│  ⭐ 평판 뱃지 ×3 · 거래 12     │
│  활동지역: 강서 · 여주          │
│  출동일정: 토 여주 / 일 김포    │  ← 텍스트(실시간GPS 아님)
│  소개: "구찌·버버리 전문..."    │
│  ─ 전문 대행자면 ─            │
│  상호/사업자번호/연락처 표시    │  ← 통신판매중개의뢰자 정보
│  [공동대행 슬롯: 토 여주 5자리] │
├─────────────────────────────┤
│        [ 채팅으로 매칭 ]       │
└─────────────────────────────┘
```

### S4. 역경매 요청 올리기 (구매자)
```
┌─────────────────────────────┐
│ ← 대행 요청(역경매)            │
│ 무엇을  [ 버버리 셔츠 M ]      │
│ 옵션    [색▾][사이즈▾] 수량[1] │
│ 얼마에  [ 50,000 ]원          │
│   ⓘ 대행료·배송 포함 희망가     │
│ 언제까지 [ 이번 주말 ▾ ]       │
│ 지역    [ 여주 ▾ ]            │
│ 메모    [______________]      │
│ ⓘ 결제는 대행자 채택·확인가     │
│   후, 직접 or 안전결제로 진행   │
│        [ 요청 올리기 ]         │
└─────────────────────────────┘
```

### S5. 매칭 채팅 + 거래방식 선택
```
┌─────────────────────────────┐
│ ← OO 대행 ⟷ 나          [🚩]  │
│  ⓘ Outget은 거래 당사자가 아님 │
│ ─────────────────────────── │
│  대행: 여주 도착, 39,000 확인  │
│  나: 진행할게요               │
│ ─────────────────────────── │
│  거래 방식 선택               │
│  ┌─────────────┬──────────┐ │
│  │ 🛡 안전결제   │ 🤝 직접거래 │ │
│  │ (페이링크)   │           │ │
│  └─────────────┴──────────┘ │
│  ⚠ 직접거래 선택 시: 선입금·   │  ← 사기 경고
│    외부채널 유도 주의. 안전결제 │
│    권장. 링크 안전성은 플랫폼이 │
│    보증하지 않습니다.          │
│  [메시지 입력 ____________]   │
└─────────────────────────────┘
```
- 안전결제 선택 → 외부 페이링크(네이버페이/토스/KCP류) 안내·딥링크(플랫폼 자금 미보유).
- **링크 검증기 없음**(보증=책임 인수 회피). 경고+권장만.

### S6. 할인소식/제보 올리기 폼 — 표시광고 방어
```
┌─────────────────────────────┐
│ ← 할인소식 올리기             │
│ 품목/브랜드 [____________]    │
│ 할인     [ 30 ]% 또는 [____]원│
│ 정가(선택) [____________]     │  ← Optional
│   ⓘ 미입력 시 '기준가 미확인'  │
│      라벨이 자동으로 붙어요    │
│ 출처     [ 매장 현장 ▾ ]      │  ← 필수
│ 사진     [📷 직접 촬영분만]    │  ← 불펌 금지 안내
│ ⓘ 허위·불펌 게시물은 신고 시   │
│   즉시 블라인드됩니다          │
│        [ 올리기 ]             │
└─────────────────────────────┘
```

### S7. 바운티(현장확인 미션) — 무금전·뱃지
```
┌─────────────────────────────┐
│ 현장 확인 미션                │
│ "여주 나이키 270 에어맥스97    │

│  보상: 🏅 확인러 뱃지 + 평판   │  ← 금전 아님
│  [ 내가 확인해줄게요 ]         │
│  (사진 제출 → 뱃지 지급)       │
└─────────────────────────────┘
```

### S8. 공동대행 슬롯 개설/참여 — 경고 모달
```
┌─────────────────────────────┐
│  ⚠ 공동대행 안내              │
│  대량 구매는 '사입(도소매)'으로 │
│  간주되어 세무 리스크가 있어요.│
│  각 요청은 반드시 '요청 접수    │
│  후 구매'하세요(선사입 금지).  │
│  [ 이해했어요, 계속 ]         │
└─────────────────────────────┘
```

### S9. 신고 → 블라인드(임시조치) + 이의
```
신고 접수 → 즉시 블라인드 → 작성자 알림
 → [이의/재게시 요청] → 운영자 검토 → 복구 or 삭제
```

## 4. 주요 사용자 플로우

### 구매자
```
지도(S1·요청 토글) or 대행자 탐색 → 역경매 요청(S4) or 대행자 채팅(S3)
 → 매칭 채팅(S5) → 거래방식 선택(안전결제 권장) → (외부)결제·수령 → 평판/뱃지
```

### 대행자(개인/전문)
```
가입 시 지위 선택(개인/전문 인증) → 광고·일정 게시(S3) / 공동대행 슬롯(S8)
 → 구매자 요청 채택 or 채팅 수신(S5) → 현장 확인가 갱신·할인소식 제보(S2/S6)
 → 거래(직접/안전결제) → 평판 뱃지
```

### 제보자 / 바운티
```
할인소식 올리기(S6) → 미검증 라벨로 노출 → (신고 시 블라인드 S9)
바운티 수행(S7) → 사진 제출 → 뱃지·평판
```

### 분쟁
```
채팅(S5) [🚩] or 거래 후 분쟁 신고 → 증빙 → 운영자 중재(반품/제재) → 기록
```

## 5. 컴포넌트 시스템 (핵심)

| 컴포넌트 | 역할 | 컴플라이언스 규칙 |
|---|---|---|
| **AgentCard** | 대행자 광고/일정/평판 | 지위 뱃지(개인/전문) 필수. 전문=사업자정보 노출 |
| **RequestCard** | 역경매 요청 | 언제까지/무엇/얼마 명확 |
| **DiscountPost(UGC)** | 할인소식 | "미검증 제보"+출처+작성자+시각. 정가 미입력→`기준가 미확인` 자동. 할인 부분 중심, 단정 표기 금지 |
| **VerifiedPriceCard** | 현장 확인가 | 단일가·대행자·확인일·✅·초록. UGC와 시각 분리 |
| **IntermediaryNotice** | 통신판매중개 고지 | 요청/소식/채팅/프로필 상시 |
| **PaymentChoice** | 직접/안전결제 선택 | 안전결제 넛지 + 직접거래 사기 경고. **링크 보증 안 함** |
| **StatusToggle(개인/전문)** | 대행자 지위 | 개인=사업자 의무 경고 상시 |
| **ReportButton → BlindFlow** | 신고·임시조치 | 모든 UGC. 즉시 블라인드 + 이의/재게시 |
| **BadgeReputation** | 평판/뱃지 | 바운티·거래 신뢰 시그널(무금전) |
| **GroupSlotWarning** | 공동대행 경고 | 사입·세무 경고 + 결제후구매 동의 |
| **EmptyState** | 데이터 없음 | 가짜 채움 금지, 제보/시드 유도 |
| **MapCluster** | 지도 핀/클러스터 | 모바일 성능 우선 |

### 색·위계 (혼동 방지)
- **현장 확인가** = 초록·✅·굵게·상단. **UGC 할인소식** = 중립/회색·"미검증" 칩·할인 부분 강조. 색 단독 의존 금지(라벨·아이콘 병행).

## 7. 접근성·모바일·상태

- **모바일 우선**: 1차 액션(요청·채택·채팅·올리기)을 엄지 영역에.
- **상태 뱃지**: 요청(대기·채택·매칭·진행·종료) / 신고(정상·블라인드·복구) 일관 색.
- **알림**: 채택·채팅·바운티 제출·신고 처리 시점.
- **로딩**: 지도·리스트 비동기, 스켈레톤.
- **접근성**: 가격·지위·상태를 색에만 의존하지 않음(색각 고려).
