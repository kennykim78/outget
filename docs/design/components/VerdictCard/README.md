# VerdictCard
The spec-check result. Two judgement lines, always in this order: **제품 규격** (`ok` ✓ · `below-recommended` △ · `below-min` ✕ · `check` ?) and **내 환경 호환** (`ok` · `check` · `below-min` · `none` = no cage context, shown as a link to register one). Each line is its status color on its soft ground with a one-sentence reason; the headline number is `spec-lg`. Below: alternatives (if any) and the one filled CTA "이 조건으로 찾기". This is the most tool-like surface in the product: no mascot, no illustration, status colors are the only color. Provide `product`, `context`, `reasons`, `alternatives[]`, `searchKeyword`.
