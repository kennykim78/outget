# ProductCard
A curated product for discovery (Phase 0): image 1:1 (operator-provided only; otherwise a `bg-100` tile with the supply glyph and "이미지 준비 중"), name on one line, spec line in `ink-muted` `tabular-nums`, `✓ 기준 충족` chip (`status-ready` on `status-ready-soft`, always present — a product that does not meet the minimum spec is never shown), ♥ as an outline icon in `status-later`; the count appears only above the threshold. Width `product-card-w` (140 mobile / 176 desktop), `radius-md`, 1px `line`. No price, seller, discount, rating, badge, mascot or "구매". Tap opens the product detail layer, whose only CTA is "이 조건으로 찾기".
