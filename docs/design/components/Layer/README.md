# Layer
The container for every tool: bottom sheet ≤767 (`radius-lg` top corners, grab handle, `shadow-sheet`), center modal ≥768 (600 / `modal-w`), right drawer ≥1024 (`drawer-w`) for supply and product detail. The page behind stays under a `rgba(47,43,39,.42)` scrim and keeps its scroll. Anatomy: optional `bg-100` summary band (checklist: "오늘 바로 데려와도 되는 준비 · 필수 2개 미완료" + progress) or a plain title row with ✕; body; footer with at most one filled CTA and a fixed line of `meta` ("이 기기에만 저장돼요"). Steps (2질문, 내 케이지, 잘 모르겠어요) replace the body inside the same layer; back returns to the previous step, then closes. Never stack two layers.
