# Outget (아웃겟) — 제품 개요

> 지도 기반 아울렛 구매대행 **매칭 보드**. 당근마켓처럼 **현장 구매대행자와 구매자의 리스트가 지도 위에** 보이고,
> 흩어진 아울렛 할인 소식을 모은다. 플랫폼은 **정보·매칭만** 제공하고 **결제·계약 당사자가 아니다.**
> 데이터를 긁지 않고, **창업자 시드 + 거래·UGC가 내 소유 데이터**를 만든다.
>
> *(코드네임 `knockedu`/LECV는 교육포털에서 피벗한 legacy. 2026-06-08 아울렛 매칭 보드로 수렴.)*

## 상태
Greenfield. 코드 없음. 사업모델 수렴 완료 → **기획서·UX v0.2 작성 완료**([planning-artifacts/](planning-artifacts/)). 스택 미확정. 하네스·BMAD·Superpowers 설정 완료(하네스 코드는 매칭/UGC/컴플라이언스용 재배선 pending).

## 핵심 가치
- "여주/김포 아울렛 특가를, 안 가도 대행으로." + "흩어진 할인 소식을 지도 한 장으로." + "대행자·구매자를 지도에서 바로 매칭."
- 코어 동력은 데이터·기술이 아니라 **① 신뢰 가능한 대행자 공급 ② 매칭·분쟁 해결**.

## 지켜야 할 불변식 (5)
1. **무크롤링(UGC 포함).** 자동 수집 금지. 시드 = 창업자 수동 큐레이션(사실/직접촬영) + 현장 출동 + UGC. UGC 불펌 금지 → 신고 시 즉시 블라인드(notice-and-takedown).
2. **자금 미보유.** 통합 에스크로 없음. **직접거래 + 외부 P2P 안전결제(페이링크류)** 병행, 자금이 플랫폼 미경유. 외부 링크 안전성 보증 안 함(검증기 미도입).
3. **통신판매중개자(판매자 아님).** 거래 화면마다 고지. 가격확정·결제·배송 비관여. **단 최소 의무 유지**(고지·신원정보 제공·분쟁 채널) — 완전 블라인드 금지.
4. **가격은 UGC + 현장확인가만.** 플랫폼이 가격 주장 안 함. UGC 할인소식(미검증·`기준가 미확인` 라벨) ↔ 현장 확인가(✅) 시각·문구 분리.
5. **대행자 지위 + 거래 무결성.** 개인(비사업자)/전문(사업자 인증) 구분 + 개인 사업자등록 의무 고지. 공동대행은 사입·세무 경고 + 결제후구매 안내. 바운티는 무금전(뱃지).

## 거래·매칭 플로우 (당근형 양면)
```
[공급] 대행자: 광고·활동지역·출동일정 게시 (개인/전문 지위)
[수요] 구매자: 역경매 요청 "언제까지·무엇을·얼마에" 게시
[정보] 대행자·제보자: 할인소식(미검증) / 대행자: 현장 확인가
   → 매칭(채택/채팅) → 거래방식 선택(직접 / 외부 안전결제) → 거래·평판 뱃지
   ※ 결제는 플랫폼 밖. 신고→블라인드·분쟁 채널은 플랫폼이 운영.
```

## MVP 범위
**In:** 앵커 1곳(여주/김포, 지역 비종속) · 지도 양면 보드(대행자/요청/할인) · UGC 할인소식+현장확인가 · 역경매 · 매칭 채팅 · 직접+외부 안전결제 · 대행자 지위구분 · 바운티 뱃지 · 공동대행(경고) · UGC 거버넌스(신고→블라인드) · 창업자 시드.
**Out (Phase 2+):** 전국 확장 · 자동매칭 알고리즘 · LLM/OCR 정제 · 벡터DB/RAG · 어필리에이트 · 중개수수료 · 내장 에스크로 · 매장 매니저 직접 피드(공식 입점 형태로만 재검토).

## 리스크 → 대응 (우선순위)
| 순위 | 리스크 | 완화 |
|---|---|---|
| 🔴 1 | 데이터·양면 콜드스타트 | 창업자 시드(수동 큐레이션+현장 출동 2~4주) + 무금전 바운티 참여 |
| 🟠 2 | UGC 저작권/허위·표시광고 | 직접촬영/출처 강제 · `기준가 미확인` 자동 라벨 · 신고→블라인드·이의(takedown) |
| 🟠 3 | 대행자 사업자 지위·중개 의무 | 개인/전문 구분·고지 + 전문 사업자정보 표시 + 통신판매중개 고지 |
| 🟠 4 | 선입금 사기 | 안전결제 넛지·직접거래 경고(링크 보증 안 함) |
| 🟡 5 | 공동대행 사입·세무 | 경고 모달 + 결제후구매 안내 |
| 🟡 6 | 위치/개인정보 | 실시간 GPS 미사용, 일정·지역 단위 텍스트 |
| 🟡 7 | 페이링크 약관 | 제공사 서면 확답(M1) + 결제모듈 추상화 |

*(무크롤링·자금 미보유 결정으로 기존 "부트스트랩 크롤링 (카)목/저작권"·"PG/전자금융" 리스크는 소멸/회피.)*
